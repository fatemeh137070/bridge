# Bridge Project

این پروژه یک **Bridge** است که با استفاده از **Java** توسعه داده شده است.

## ویژگی‌ها
- استفاده از **Java 21**
- طراحی **ماژولار** با **Maven**
- مدیریت **فایل‌ها و داده‌ها** در **MongoDB**
- تولید گزارش‌ها در **PDF** با **iText**
